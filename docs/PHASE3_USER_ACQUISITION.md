# User Acquisition Strategy - Phase 3 Submission

**User Acquisition Strategy**

**Phase 1 — Product-Led Growth (Month 1)**

- Free tier already better than Snowtrace — users try it, love it, upgrade to Pro
- Viral sharing: shareable URLs with contract analytics
- SEO: rank for "Avalanche contract analytics", "AVAX scanner alternative"

**Phase 2 — Community Channels (Months 2-3)**

- Avalanche Discord — share in #builds, #showcase channels
- Twitter/X — post analytics of trending contracts, thread about features
- Reddit r/avalanche — share tool in relevant threads
- Developer meetups — present at Avalanche-focused events

**Phase 3 — Partnerships (Months 3-6)**

- Integrate with popular protocols — offer them white-label analytics
- Avalanche Foundation — apply for ecosystem grants
- Hackathon winners publicity — leverage Build Games 2026 press

**Conversion Funnel:**

1. Land: User searches "Avalanche contract analytics" → finds AvaxLens
2. Try: Uses free tier → sees value immediately (no signup needed)
3. Convert: Hits limit (4 AI audits) → upgrades to Pro for unlimited
4. Retain: Alerts + comparison + API keep them on Pro

**Why this works:**

- No signup barrier for first use → high conversion
- Competitors require signup or payment → we win on friction
- Avalanche ecosystem growing → organic traffic from new developers

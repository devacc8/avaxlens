# Community Strategy - Phase 3 Submission

**Community Strategy**

**Discord Server**

- Main hub for support, feedback, feature requests
- Channels: #general, #feedback, #showcase (users share their projects), #help
- Weekly "Contract of the Week" — highlight interesting Avalanche contracts
- Bot that notifies on new AI audit completions for watched contracts

**Twitter/X**

- Share analytics of trending contracts
- Thread: "How to audit any AVAX contract in 60 seconds"
- Reply to Avalanche ecosystem news with relevant data
- Engage with developers building on Avalanche

**Content & Education**

- Blog: "How we built AvaxLens", "Contract security best practices"
- YouTube: Tutorials on using analytics features
- GitHub: Open source some components, encourage contributions

**Community Programs**

- "AvaxLens Ambassador" — top contributors get free Pro tier
- Feature voting — community votes on what to build next
- Bug bounty — reward for security findings

**Events**

- Attend Avalanche Summit, community meetups
- Sponsor hackathons — provide free analytics for participants
- Present at Avalanche-focused developer events

**Governance**

- Keep it simple initially — direct feedback via Discord
- Later: community governance for major feature decisions
- Transparent roadmap updates every month
